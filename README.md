Employee Directory Application

About the Project
The Employee Directory is a web-based application developed using Symfony, PHP, and MySQL to manage employee information efficiently.

It provides secure CRUD (Create, Read, Update, Delete) operations, allowing users to add, view, update, and delete employee records through a centralized system.

Features
- Add new employee records
- View employee information
- Update existing employee details
- Delete employee records
- Secure CRUD operations
- Centralized employee data management
- Efficient employee information retrieval

Technologies Used
- Backend: PHP, Symfony
- Database: MySQL
- Frontend: HTML, CSS, JavaScript
- Tools: Git, GitHub, VS Code

Key Achievements
- Built an Employee Directory application with secure CRUD operations using Symfony, PHP, and MySQL.
- Reduced employee information retrieval latency by 60% through optimized data handling and database operations.

Application Workflow
1. Users access the employee directory.
2. Employee records are retrieved from the MySQL database.
3. Users can add, view, update, and delete employee information.
4. The application processes requests through Symfony backend services.
5. Updated information is stored in the database.

Installation and Setup

1. Clone the Repository
```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

2. Navigate to the Project
```bash
cd employee-directory
```

3. Install Dependencies
```bash
composer install
```

4. Configure the Database
Update your database connection settings in the `.env` file.

5. Run Database Migrations
```bash
php bin/console doctrine:migrations:migrate
```

6. Start the Application
```bash
symfony server:start
```
